# Insignia Verification Workflow

Скилл для автоматизированной проверки качества кода перед коммитом или передачей задачи человеку.

## 🚀 Команды верификации

Каждый агент перед завершением работы запускает следующую последовательность команд:

```bash
# 1. Форматирование всех измененных файлов по правилам bunfig.toml:
bun fmt

# 2. Проверка типов компилятором во всех воркспейсах:
bun check

# 3. Валидация через встроенные проверки hk:
hk check
```

## 🔍 Критерии приёмки

- `bun fmt` не должен возвращать незафиксированных изменений.
- `bun check` должен возвращать `✓ No type errors`.
- `hk check` должен завершаться с кодом 0 без предупреждений о конфликтах регистра, приватных ключах или невалидных переводах строк.
