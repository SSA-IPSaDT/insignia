# @insignia/contracts

Пакет разделяемых контрактов, схем валидации и DTO (Data Transfer Objects) платформы **Insignia**. Служит единым источником правды (Single Source of Truth) для типов данных между клиентом и сервером.

---

## 🎯 Назначение

- Устранение рассинхронизации данных между бэкендом (`apps/api`), фронтендом (`apps/web`) и ботом (`apps/bot`).
- Декларативное описание структур входящих и исходящих данных, параметров эндпоинтов и ошибок.
- Повторное использование схем валидации на клиенте и на сервере.

---

## 📐 Архитектурные правила

1. **Платформенная независимость**: Код пакета должен оставаться изоморфным и чистым. Запрещены прямые зависимости от Node.js/Bun системных модулей (`node:fs`, `node:child_process`) или браузерного API (`window`, `document`).
2. **Экспорт только контрактов**: Пакет не содержит логики работы с базой данных, внешних сетевых вызовов или бизнес-процессов.
3. **Строгая типизация**: Каждая схема валидации должна экспортировать соответствующий инференс типа TypeScript:
    ```typescript
    export type UserDto = z.infer<typeof userSchema>;
    ```

---

## 🚀 Использование в других модулях

```typescript
// В apps/api или apps/web:
import type { UserDto } from '@insignia/contracts';
import { userSchema } from '@insignia/contracts';
```
