# @insignia/database

Пакет доступа к данным и управления моделями базы данных платформы **Insignia**. Содержит схему базы данных, миграции и сгенерированный типизированный клиент ORM.

---

## 🎯 Назначение

- Централизованное управление схемой базы данных и миграциями.
- Экспорт единого сконфигурированного экземпляра клиента БД для серверных сервисов.
- Защита данных и обеспечение консистентности транзакций.

---

## 🛠 Стек технологий

- **ORM**: Prisma / Kysely
- **СУБД**: PostgreSQL (запускается локально через `infra/docker/docker.compose.yml`)
- **Язык**: TypeScript (строгий режим)

---

## ⚠️ Правила использования и безопасности

- **Доступ разрешен только серверным модулям**: Пакет импортируется исключительно в `apps/api` (и при необходимости в `apps/bot`).
- **Строгий запрет на импорт в клиентский код**: Категорически запрещено импортировать `@insignia/database` в `apps/web`. Клиентский код никогда не должен иметь прямого доступа к базе данных или учетным записям подключения.
- **Миграции через систему контроля версий**: Все изменения схемы генерируют файлы миграций, которые коммитятся в репозиторий.

---

## 🚀 Полезные команды

```bash
# Применение миграций локально:
moon run database:migrate

# Запуск локальной БД в Docker:
docker compose -f infra/docker/docker.compose.yml up -d
```
