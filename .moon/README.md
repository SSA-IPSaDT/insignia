# Moonrepo (.moon)

Директория конфигурации оркестратора монорепозитория **Moonrepo (Moon)** для платформы **Insignia**.

---

## 🎯 Назначение

Moonrepo управляет графом зависимостей подпроектов, кэшированием результатов сборки и скоординированным запуском задач (`dev`, `build`, `typecheck`, `test`) во всем монорепозитории.

---

## 📁 Структура конфигурации

- `workspace.yml` — корневая конфигурация рабочей области:
    - `projects` — шаблоны поиска проектов (`apps/*`, `packages/*`, `infra/*`).
    - `vcs` — интеграция с системой контроля версий Git (провайдер `github`, ветка по умолчанию `master`).
- `cache/` — локальный кэш хэшей и артефактов Moon (добавлен в `.gitignore`).

---

## 🚀 Полезные команды Moon

```bash
# Просмотр графа всех проектов и их зависимостей:
moon project --all

# Детальная информация по конкретному проекту:
moon project api
moon project web

# Запуск задачи для всех затронутых (affected) проектов:
moon run :build

# Запуск задачи для конкретного проекта:
moon run api:dev
moon run bot:dev
moon run web:dev

# Проверка графа задач:
moon action-graph
```
