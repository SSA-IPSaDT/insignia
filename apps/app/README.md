# @insignia/app

Клиентское кроссплатформенное приложение платформы **Insignia** (Telegram Mini App, VK Mini App, Max, Standalone Web & PWA). Построено на базе современного стека **Svelte 5** и **SvelteKit** для достижения максимальной скорости рендеринга и реактивности без оверхеда виртуального DOM.

---

## 🎯 Назначение

- Интерактивный пользовательский интерфейс для работы во всех поддерживаемых средах (Mini Apps в мессенджерах, мобильное PWA и браузер).
- Прохождение форм, просмотр мероприятий, управление профилем.
- Взаимодействие с бэкенд API (`apps/api`) через изоморфный `@insignia/sdk`.
- Строгая валидация и типизация входящих данных через `@insignia/contracts`.

---

## 🛠 Стек технологий

- **Фреймворк**: [Svelte 5](https://svelte.dev/) (с синтаксисом Runes `$state`, `$derived`, `$props`)
- **Мета-фреймворк**: [SvelteKit](https://kit.svelte.dev/) (SSR, маршрутизация, адаптеры)
- **Сборщик**: Vite 6+
- **Рантайм**: Bun
- **Стилизация**: Tailwind CSS (с автосортировкой классов в `bunfig.toml`)
- **Контракты данных**: `@insignia/contracts`
- **Язык**: TypeScript (строгий режим)

---

## 📦 Взаимодействие в монорепозитории

- Зависит от:
    - `packages/contracts` (типы DTO, валидация пользовательского ввода)
    - `packages/sdk` (клиентский изоморфный SDK для работы с API)
    - `infra/env` (типизированные переменные окружения)
    - `packages/tsconfig` (общие настройки компилятора)
- **Правило изоляции**: Приложение выполняется на стороне клиента и в изолированном SSR-слое. Прямой импорт `@insignia/database` **категорически запрещен**. Все операции с данными осуществляются исключительно через сетевые вызовы к `apps/api`.

---

## 🚀 Разработка

Все команды можно запускать из корня репозитория или непосредственно из директории `apps/app`:

```bash
# Запуск dev-сервера с горячей перезагрузкой:
bun run dev
# или через Moonrepo из корня:
moon run app:dev

# Проверка типов Svelte и TypeScript:
bun run check

# Сборка для продакшена:
bun run build

# Предпросмотр продакшен-сборки:
bun run preview
```
