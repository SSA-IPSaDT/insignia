# @insignia/api

Серверный сервис платформы **Insignia**. Предоставляет REST / RPC эндпоинты для веб-клиента (`apps/web`), сервиса бота (`apps/bot`) и внешних интеграций.

---

## 🎯 Назначение

- Аутентификация и авторизация пользователей и сервисов.
- Обработка бизнес-логики платформы.
- Взаимодействие с базой данных через `@insignia/database`.
- Строгое соответствие API-контрактам из `@insignia/contracts`.

---

## 🛠 Стек технологий

- **Рантайм**: Bun
- **Язык**: TypeScript (строгий режим)
- **Контракты и валидация**: `@insignia/contracts`
- **Доступ к данным**: `@insignia/database`

---

## 📦 Взаимодействие в монорепозитории

- Зависит от:
    - `packages/contracts` (типы DTO, схемы запросов/ответов)
    - `packages/database` (доступ к моделям и транзакциям БД)
    - `packages/tsconfig` (базовые настройки TS)
- **Не должен напрямую импортировать код из `apps/web` или `apps/bot`!**

---

## 🚀 Разработка

Все команды запускаются из корня репозитория через `moon` или `bun`:

```bash
# Запуск в режиме разработки с автоперезагрузкой:
moon run api:dev

# Проверка типов:
moon run api:typecheck
```
