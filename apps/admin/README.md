# @insignia/admin

Панель администратора платформы **Insignia**. Построена на базе современного стека **Svelte 5** (Runes), **SvelteKit**, **Tailwind CSS v4** и **MDSveX** для управления ресурсами, пользователями и аналитикой платформы.

---

## 🎯 Назначение

- Управление пользователями, ролями и доступами платформы.
- Мониторинг состояния сервисов и просмотр метрик.
- Управление контентом, тарифами и конфигурациями системы.
- Взаимодействие с бэкенд API (`apps/api`) по протоколам REST/RPC.
- Строгая валидация и типизация входящих данных через `@insignia/contracts`.

---

## 🛠 Стек технологий

- **Фреймворк**: [Svelte 5](https://svelte.dev/) (с синтаксисом Runes `$state`, `$derived`, `$props`)
- **Мета-фреймворк**: [SvelteKit](https://kit.svelte.dev/) (SSR, маршрутизация, адаптер `@sveltejs/adapter-bun`)
- **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/) (`@tailwindcss/vite`, `@tailwindcss/forms`, `@tailwindcss/typography`)
- **Контент**: [MDSveX](https://mdsvex.pngwn.io/) (Markdown в компонентах Svelte)
- **Сборщик**: Vite 8+
- **Рантайм**: Bun
- **Контракты данных**: `@insignia/contracts`
- **Язык**: TypeScript (строгий режим)

---

## 📦 Взаимодействие в монорепозитории

- Зависит от:
    - `packages/contracts` (типы DTO, валидация данных)
    - `packages/sdk` (клиентский изоморфный SDK для работы с API)
    - `packages/logger` (структурированное логирование)
    - `infra/env` (типизированные переменные окружения)
    - `packages/tsconfig` (общие настройки компилятора)
- **Правило изоляции**: Приложение панели администратора выполняется изолированно. Прямой импорт `@insignia/database` **категорически запрещен**. Все операции с данными осуществляются исключительно через сетевые вызовы к `apps/api`.

---

## 🚀 Разработка

Все команды можно запускать из корня репозитория или непосредственно из директории `apps/admin`:

```bash
# Запуск dev-сервера с горячей перезагрузкой:
bun run dev
# или через Moonrepo из корня:
moon run admin:dev
# или через корневой bun:
bun run dev:admin

# Проверка типов Svelte и TypeScript:
bun run check

# Сборка для продакшена:
bun run build

# Предпросмотр продакшен-сборки:
bun run preview
```
