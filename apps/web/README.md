# @insignia/web

Пользовательский веб-интерфейс платформы **Insignia**. Построен на базе современного стека **Svelte 5** и **SvelteKit** для достижения максимальной скорости рендеринга и реактивности без оверхеда виртуального DOM.

---

## 🎯 Назначение

- Интерактивный пользовательский кабинет и панель управления платформой.
- Визуализация данных, аналитика и управление настройками.
- Взаимодействие с бэкенд API (`apps/api`) по протоколам REST/RPC.
- Строгая валидация и типизация входящих данных через `@insignia/contracts`.

---

## 🛠 Стек технологий

- **Фреймворк**: [Svelte 5](https://svelte.dev/) (с синтаксисом Runes `$state`, `$derived`, `$props`)
- **Мета-фреймворк**: [SvelteKit](https://kit.svelte.dev/) (SSR, маршрутизация, адаптеры)
- **Сборщик**: Vite 6+
- **Рантайм**: Bun
- **Стилизация**: Tailwind CSS (с автосортировкой классов в `bunfig.toml`)
- **Контракты данных**: `@insignia/contracts`
- **Язык**: TypeScript (строгий режим)

---

## 📦 Взаимодействие в монорепозитории

- Зависит от:
    - `packages/contracts` (типы DTO, валидация пользовательского ввода)
    - `packages/tsconfig` (общие настройки компилятора)
- **Правило изоляции**: Веб-приложение выполняется на стороне клиента и в изолированном SSR-слое. Прямой импорт `@insignia/database` **категорически запрещен**. Все операции с данными осуществляются исключительно через сетевые вызовы к `apps/api`.

---

## 🚀 Разработка

Все команды можно запускать из корня репозитория или непосредственно из директории `apps/web`:

```bash
# Запуск dev-сервера с горячей перезагрузкой:
bun run dev
# или через Moonrepo из корня:
moon run web:dev

# Проверка типов Svelte и TypeScript:
bun run check

# Сборка для продакшена:
bun run build

# Предпросмотр продакшен-сборки:
bun run preview
```
