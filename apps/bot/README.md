# @insignia/bot

Фоновый сервис бота и автоматизации платформы **Insignia**. Обеспечивает взаимодействие с внешними платформами (мессенджеры, вебхуки, фоновые очереди).

---

## 🎯 Назначение

- Интеграция с мессенджерами (Telegram, Discord) и обработка команд пользователей.
- Отправка уведомлений, оповещений и статусных сообщений.
- Фоновая автоматизация периодических задач.

---

## 🛠 Стек технологий

- **Рантайм**: Bun
- **Язык**: TypeScript (строгий режим)
- **Контракты данных**: `@insignia/contracts`
- **Доступ к БД**: `@insignia/database`

---

## 📦 Взаимодействие в монорепозитории

- Зависит от:
    - `packages/contracts` (общие типы и контракты)
    - `packages/database` (работа с пользователями и состоянием)
- Взаимодействует с `apps/api` исключительно через сетевые протоколы (HTTP/RPC).
- Не содержит прямого связывания с веб-интерфейсом.

---

# Запуск бота в dev-режиме:
