# @insignia/bot

Сервис Telegram-бота платформы **Insignia**.

---

## 🎯 Назначение

- Обработка команд пользователей и администраторов в Telegram.
- Отправка уведомлений и оповещений.
- Привязка Telegram-аккаунтов к платформе.
- Поддержка режимов работы через Long Polling и Webhooks.

---

## 🛠 Стек технологий

- **Рантайм**: Bun
- **Язык**: TypeScript
- **Контракты данных**: `@insignia/contracts`

---

## 📦 Взаимодействие в монорепозитории

- Зависит от:
    - `packages/contracts` (типы DTO)
    - `packages/sdk` (клиентский изоморфный SDK для вызовов API)
    - `packages/logger` (структурированное логирование)
    - `infra/env` (типизированные переменные окружения)
    - `packages/tsconfig` (общие настройки компилятора)
- Взаимодействует с `apps/api` через клиентский SDK `@insignia/sdk` по HTTP/RPC.

---
